## 📌 About The Project

This project is my personal developer portfolio website, designed to provide a
professional overview of my technical background, projects, certifications,
education, experience and development skills.

The portfolio focuses on a modern UI, responsive design, smooth interactions
and a structured presentation of my work across:

- Frontend Development
- React & React Native
- Java Full Stack Development
- AWS Cloud
- ETL & Data Engineering
- SQL & Data Warehousing
- Web Development
- Mobile Application Development

The website is designed to be useful for recruiters, hiring managers,
potential clients and developers who want to explore my work and technical
background.

The main objectives of this portfolio are:

## 📊 AWS ETL Pipeline

### Category

Cloud Data Engineering

### Technologies

- Amazon S3
- AWS Glue
- Amazon Redshift
- SQL
- PySpark
- Data Engineering

### Overview

A conceptual cloud-based ETL architecture demonstrating the flow of data from
different source systems through data extraction, transformation and loading
into a cloud data warehouse.

The architecture represents the following learning workflow:

```text
Source Data
    ↓
MySQL / RDBMS / NoSQL / Text Logs
    ↓
Extract
    ↓
Data Lake
    ↓
Amazon S3 / HDFS / Google Cloud Storage
    ↓
AWS Glue
    ↓
Transform
    ↓
PySpark / Databricks / AWS Glue
    ↓
Load
    ↓
Amazon Redshift
    ↓
Snowflake / Power BI / SQL Analytics
